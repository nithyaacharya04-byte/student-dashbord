3. Project Description
Writing
About the Project
The Student Performance Analysis Dashboard is a data analytics project developed using Microsoft Excel to analyze students' examination scores and identify factors associated with their academic performance.
The project uses student data containing gender, race/ethnicity group, parental education level, lunch type, test preparation course status, and mathematics, reading, and writing scores.
Using Excel data analysis features and PivotTables, the project organizes and summarizes student information to compare academic performance across different categories. The analysis helps identify performance patterns and provides insights that may support educational decision-making.

4. Purpose of the Project
The main objectives of this project are:
To analyze students' mathematics, reading, and writing scores.
To compare academic performance across genders.
To examine performance differences among race/ethnicity groups.
To explore the relationship between parental education and examination scores.
To compare students who completed test preparation courses with those who did not.
To analyze score patterns according to lunch type.
To summarize student performance using Excel PivotTables and dashboard visualizations.
To support data-driven decisions in education.
Important: These factors can be associated with differences in scores, but this analysis alone cannot establish that they cause those differences.
